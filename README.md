# 🔍 Instagram Unfollowers Checker (inst-checker)

Умный и точный инструмент на Python для проверки взаимности подписок в Instagram. Находит пользователей, на которых вы подписаны, но которые **не подписаны на вас в ответ**, а также выявляет ваших **фанатов** (кто подписан на вас, но не вы).

---

## ✨ Ключевые возможности

* **🎯 100% точность (Zero False Positives):** Instagram часто обрывает пагинацию при выгрузке списков (например, отдаёт только 100–200 человек). Наш скрипт индивидуально верифицирует каждого кандидата через приватный API отношений (`followed_by`) и поиск. Ваши реальные друзья **никогда** не попадут в список невзаимных по ошибке.
* **⚡ Многоуровневый добор:** Безопасный сбор данных порциями по 50 через v1 Mobile API с автоматическим добором через Private GraphQL и Public GraphQL.
* **🔑 Безопасная авторизация без рутины:**
  * Чтение данных из `.env` (не нужно вводить логин и пароль каждый раз).
  * Поддержка входа без пароля по cookie `sessionid` (обходит любые проверки и блокировки входа).
  * Кэширование сессии в `session.json` — повторные запуски происходят мгновенно.
  * Поддержка 2FA и проверок безопасности (Challenge/SMS/Email).
* **📊 Детальная аналитика и удобные форматы экспорта:**
  * `not_following_back.txt` — чистые никнеймы построчно (удобно для скриптов и отписок).
  * `not_following_back_details.txt` — никнеймы, имена и прямые ссылки на профили.
  * `fans.txt` — список фанатов (подписаны на вас, но вы не подписаны в ответ).
* **🛡️ Защита от блокировок:** Умные рандомизированные паузы между запросами, имитирующие поведение официального приложения.

## 🚀 Быстрый старт

### 1. Клонирование и установка зависимостей

```bash
git clone https://github.com/madiyar-abi/inst-checker.git
cd inst-checker
pip install -r requirements.txt
```

### 2. Настройка конфигурации (`.env`)

Скопируйте шаблон конфигурации:

```bash
cp .env.example .env
```

Откройте созданный `.env` и укажите данные для входа одним из двух способов:

#### Способ А: Логин и пароль (стандартный)
```env
INSTAGRAM_USERNAME=ваш_логин
INSTAGRAM_PASSWORD=ваш_пароль
```

#### Способ Б: Вход по `sessionid` (без ввода пароля)
> 💡 Рекомендуется, если Instagram запрашивает подтверждения входа или блокирует мобильный логин.
1. Откройте [instagram.com](https://instagram.com) в браузере (где вы уже авторизованы).
2. Нажмите `F12` (или `Cmd + Option + I` на Mac) ➔ вкладка **Application** (или *Хранилище*) ➔ **Cookies** ➔ `https://www.instagram.com`.
3. Скопируйте значение cookie `sessionid`.
4. Вставьте его в `.env`:
```env
INSTAGRAM_SESSIONID=ваш_скопированный_sessionid
```

### 3. Запуск

```bash
python main.py
```

## ⚙️ Дополнительные параметры запуска

| Флаг | Описание |
| :--- | :--- |
| `--fresh` | Игнорировать `session.json` и выполнить чистый повторный вход |
| `--skip-verify` | Пропустить этап индивидуальной верификации кандидатов (для максимальной скорости) |
| `-u`, `--username` | Передать имя пользователя через аргументы командной строки |
| `-p`, `--password` | Передать пароль через аргументы командной строки |
| `-o`, `--output` | Задать пользовательский путь для сохранения файла со списком невзаимных |

## 🔒 Безопасность и конфиденциальность

* Ваши учётные данные и токены сессий **хранятся исключительно локально** на вашем компьютере в файле `.env` и `session.json`.
* Файлы `.env`, `session.json` и все файлы с результатами сканирования внесены в `.gitignore` и **никогда не попадут в репозиторий Git**.
* Скрипт взаимодействует только напрямую с серверами Instagram через библиотеку `instagrapi`.
